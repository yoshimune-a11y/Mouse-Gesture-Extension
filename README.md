# Mouse Gesture for Edge

右クリックドラッグで操作する、Microsoft Edge（Chromium系）向けのマウスジェスチャー拡張機能です。Manifest V3。

## 特徴

- **右クリックドラッグ式** — 右ボタンを押しながら動かすと軌跡を描画し、認識中の動作名を表示。ボタンを離すと実行します。ジェスチャー後の右クリックメニューは自動で抑制します。
- **動作のカスタマイズ** — 方向（`U`/`D`/`L`/`R` の組み合わせ）と動作の割り当てを設定ページで自由に追加・編集・削除できます。戻る/進む/再読み込み/タブ・ウィンドウ操作など多数の動作に対応。
- **指定URLを開く** — 任意のジェスチャーに好きなURLを割り当てて新しいタブで開けます。
- **リンク上の専用ジェスチャー** — 起点がリンクのときだけ別の動作（リンクを新しいタブ/バックグラウンド/新ウィンドウで開く、URLコピー）を実行できます。
- **ホイールでタブ移動** — 右ボタンを押しながらホイールを回すと前後のタブへ切り替え（端でループ可）。

## 既定のジェスチャー

| 操作 | 動作 |
|---|---|
| ← | 戻る |
| → | 進む |
| ↑ | ページ最上部へ |
| ↓ | ページ最下部へ |
| ↑↓ | 再読み込み |
| ↓→ | タブを閉じる |
| ↓← | 閉じたタブを復元 |
| →↑ | 新しいタブ |
| ↑→ / ↑← | 次/前のタブ |
| ↓↑ | タブを複製 |

リンク上では ↑＝新しいタブで開く、↓＝バックグラウンドで開く（変更可）。

## インストール（開発者モード）

1. このリポジトリをダウンロード（または `git clone`）します。
2. Edge で `edge://extensions` を開きます。
3. 左下の **開発者モード** をオンにします。
4. **展開して読み込み** をクリックし、このフォルダ（`manifest.json` がある場所）を選択します。

拡張機能のアイコンをクリックすると設定ページが開きます。

## 制限事項

`edge://` などのブラウザ内部ページ、新規タブページ、拡張機能ストア上ではコンテンツスクリプトが動作しないため、ジェスチャーは効きません（ブラウザ仕様）。
